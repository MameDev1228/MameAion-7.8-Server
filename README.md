# MameAion 7.8

Aion 7.8 をベースにした、**完全リワーク**を目指すプライベートサーバーエミュレーターです。  
ベースソース: [ZON3DEV/AionLightning 7.8](https://github.com/ZON3DEV/AionLightning)

---

## プロジェクトの目的

既存の 7.x 系エミュレーターは全体的に動作品質が低く、コアシステムから根本的に見直す必要があります。  
このプロジェクトは Aion 7.8 のゲーム体験をできる限り正確に再現することを目標に、**コアから徹底的にリワーク**しています。

### フォーカスエリア

- PvP / PvE システムの正確な再現
- アビスポイント / グローリーポイントの正確な計算
- 攻城戦・要塞戦の動作
- スキル蘇生・バインド蘇生・キスク蘇生の正確な挙動
- PvP 中の移動同期・ノックバック・空中戦闘の安定化
- デスペナルティ・ソウルシックネスの正確な適用
- インスタンス・クエストの正確な実装
- メモリリーク・同期バグの修正によるサーバー長期稼働の実現

---

## ビルド方法

Maven を使用します。ルートディレクトリで以下を実行してください。

```bash
git clone --recursive -b 7.8.0 https://github.com/ZON3DEV/AionLightning.git
cd AionLightning
mvn package
```

Java 11 以上が必要です。データベースは MySQL または MariaDB を使用します。

---

## サーバーセットアップ

1. 各サーバーモジュールの `sql/` フォルダ内の `.sql` ファイルでデータベースを初期化する
2. `config/` 以下の設定ファイルを環境に合わせて編集する
3. ログインサーバーの `gameserver` テーブルにゲームサーバーの接続情報を登録する

カスタム設定は `config/mygs.properties` に記述することを推奨します（アップデート時に上書きされません）。

---

## クライアントセットアップ

Aion 7.8 クライアントが必要です。  
起動スクリプト例（`start.bat`）:

```batch
start /affinity 7FFFFFFF "" "bin64\AION.bin" -ip:127.0.0.1 -port:2106 -cc:2 -lang:JPN -loginex
```

`-lang` パラメーターは `l10n` フォルダ内にインストールされている言語を指定します。
